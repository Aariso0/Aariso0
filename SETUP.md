# Aariso0 GitHub profile setup

This package fixes the broken external GitHub statistics images by generating the stats SVGs inside this repository. It also updates the recently pushed repositories section and generates a contribution graph using GitHub Actions.

## Install

1. Open the public `Aariso0/Aariso0` profile repository.
2. Copy the contents of this package into the repository root, keeping the `.github/`, `profile/`, and `scripts/` directories.
3. Commit and push to the repository's default branch.
4. Open **Settings → Actions → General → Workflow permissions** and select **Read and write permissions** if the repository is not already configured to allow workflow writes.
5. Open **Actions → Update profile content → Run workflow**.
6. Then open **Actions → Generate contribution graph → Run workflow**.

The first workflow generates `profile/stats.svg` and `profile/top-langs.svg`, and updates the recently pushed repositories section. It runs every six hours. The second workflow generates the contribution graph and runs daily.

## How the cards work

- Stats and top-language cards are generated by `stats-organization/github-readme-stats-action` and committed into `profile/`. They are served by GitHub from this repository; profile visitors do not call a third-party stats server.
- The contribution graph is generated by `alexcerezo/activity-graph` through GitHub Actions and inserted between the activity graph markers in `README.md`.
- Recently pushed repositories are fetched from the GitHub REST API, sorted by `pushed_at`, and the five newest non-fork, non-archived public repositories are displayed.

No personal access token or external secrets are required for public profile data. The workflows use the built-in `GITHUB_TOKEN`.

## Important

The two SVGs included in `profile/` are only graceful placeholders. They prevent broken-image icons before the first workflow run. The workflows replace them with generated cards after a successful run.
